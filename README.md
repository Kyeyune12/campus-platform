# campus-platform
A semester wide project

A university forum, quiz and moderation platform. Built as the practical
track of Semester I 2026/2027 (SE-EVE-2, Makerere CoCIS).

## What this is

This repository is both a working system and a portfolio. Every feature
arrives as a ticket, is built on a branch, and is merged through a pull
request that passes CI.

## Running it

```bash
git clone <this-repo>
cd campus-platform
docker compose up
```
